# Lighthouse TIMP Risk Model Refinement Prototype

This GitHub Pages site mirrors the canonical prototype from
[`JANA-Technology/Lighthouse-TIMP-Product`](https://github.com/JANA-Technology/Lighthouse-TIMP-Product/blob/main/prototypes/risk-model-refinement/lighthouse-operations-refinement-views-timp.html).

The canonical repository is internal. GitHub's default `GITHUB_TOKEN` is scoped
to the repository where a workflow runs, so this Pages repository cannot read
the canonical source in a secretless cross-repository workflow. Synchronization
must therefore run from an authenticated context with access to both repositories.
